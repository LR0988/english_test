# Liam's Wonder World 2｜黃尚霖英文複習樂園 🦁

專為 **Liam（黃尚霖）** 打造的《Wonder World 2》全書互動英語複習網站，結合 **React + TypeScript + Tailwind CSS + Supabase 雲端同步 + Vercel 自動部署**。

## ✨ 功能特色

- **全書章節完整收錄（第 4–112 頁）**：
  - **一、課前複習（Starter & Get Ready）**：動物/能力/家庭/職業複習、10 組短母音字群、8 句必學課室指令、人物猜謎（Boka / Amy / Kevin / Jello）、數字 11–20 與 `a / a_e` 自然發音。
  - **二、核心單元與複習（Units 1–4 & Reviews 1–2）**：
    - `Unit 1: The Big Wind`（天氣單字、城市預報、`-y` 字尾魔法）
    - `Unit 2: Going Back Home`（報時句型、互動時鐘、`-teen` vs `-ty` 比較）
    - `Review 1`（天氣 × 時間綜合闖關）
    - `Unit 3: Be Honest`（文具單字、`my / your` 所有格、失物招領誠實品格）
    - `Unit 4: Earthquake Drill`（`in / on / under` 位置介系詞、抗震三步驟、Go Bag 避難包、拍手數音節 Syllable Sort）
    - `Review 2`（房間物品位置偵探 Room A/B/C + Play & Say 25 字發音連線盤）
  - **三、文化節慶與跨域延伸（Culture, Task & Extras）**：
    - 萬聖節專區（Halloween）、緊急求救通報寫作產生器（Let's Write）、臺灣四大城市攝氏氣溫氣象台、世界四大著名時鐘巡禮（Big Ben / Cuckoo Clock / Grand Central / Cosmo Clock 21）。
  - **四、魔法遊戲與附錄檢核（Games & Appendices）**：
    - **Magic e 折疊翻翻字卡**、**沙灘猜拳闖關桌遊**、**女巫帽尋字雲（Word Hunt）**、**自我檢核總表（Self-Checklist）**、**A–Z 全書生字索引字典**（依課本黑/藍/綠字分級並標示教育部 1,200 字詞 `*`）。
- **四大互動練習模式**：點讀 3D 閃卡（支援正常/慢速跟讀）、聽音與看義選擇測驗、雙模拼字挑戰（平板點選字母方塊／電腦鍵盤輸入）、句子火車重組。
- **Supabase 跨裝置雲端同步**：自動儲存 XP 等級、連續學習天數、單字熟練度星等、錯題複習本與檢核勾選進度。

## 🚀 本機開發與部署

```bash
npm install
npm run dev
```
